NoxHere is a macOS menu bar app that surfaces a GitHub organization's pull-request activity. It is a native client for the unified NoxHere workspace and uses NoxConnect for GitHub access.

NO ACCOUNT OR CREDENTIALS ARE REQUIRED FOR REVIEW.

On the welcome screen, select "Preview with demo data." This creates a short-lived, read-only demo session and opens a populated demo organization. The demo contains pull requests, reviews, merges, release notes, assigned issues, several team members, filters, workload counts, and PR timelines. Demo data is isolated from production customer data.

Testing instructions:
1. Launch NoxHere. It appears as an icon in the menu bar.
2. Click the icon, then select "Preview with demo data." No GitHub login is required.
3. Use Opened, Merged, Notes, people, and repository filters to inspect the populated feed. "Load more" demonstrates pagination.
4. The "Current" tab shows who has open PRs, review requests, and assigned issues, with per-person counts. Select a person to inspect their work.
5. Click a pull-request card to open its complete activity timeline and public example GitHub link.
6. Open notification settings and use "Send test notification" to verify native macOS notification delivery.
7. Press ⌘⇧X from anywhere to open the popover using the global hotkey.
8. Open the account menu and select "Exit demo" to return to production sign-in.

The interface keeps production administrative features visible during the demo. Actions that would mutate an organization—AI-provider configuration, tracked-repository changes, team-visibility changes, adding an account, and manual synchronization—are clearly disabled because the demo workspace is read-only. The demo API also rejects every non-GET request server-side.

Production authentication:
"Sign in with GitHub" uses GitHub's OAuth Device Authorization Flow brokered by NoxConnect. NoxHere presents github.com/login/device with ASWebAuthenticationSession, shows the one-time code in the app, and waits for authorization to finish. Only short-lived NoxConnect credentials are stored in the macOS Keychain. Signing out removes the local credentials.

Organization setup behavior:
- If NoxConnect is not installed on a selected organization, NoxHere explains this and provides an Install NoxConnect button.
- If NoxConnect is installed but the organization has no activity yet, NoxHere confirms that the organization is connected and waiting for new pull-request activity.

Privacy: the app is sandboxed with only the outgoing-network entitlement. It has no third-party analytics or advertising trackers. Limited first-party lifecycle metadata is recorded through NoxConnect, and GitHub tokens live in the macOS Keychain.
