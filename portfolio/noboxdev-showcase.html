The engineer

Breadth and depth, end to end — from Rust ECS to App Store distribution to Cloudflare edge.

I run No-Box-Dev as a one-engineer software studio: I take products from problem statement to production across whichever stack fits — a sandboxed macOS menu-bar app, a Cloudflare-edge web platform, a Bevy game, or an autonomous agent pipeline. Development is AI-native: agents are first-class collaborators across the whole workspace, not an afterthought. The work below is real, running code.

Technical capabilities

Five areas, each with the actual engineering it takes to ship — and the products that prove it.

Native macOS

Sandboxed desktop apps, signable to the Mac App Store

Menu-bar-first (MenuBarExtra, LSUIElement) apps with no dock icon; Keychain + Touch ID secret storage; hardened runtime + App Sandbox; code-signing, notarization, and fastlane MAS pipelines; global hotkeys; in-app MCP servers over a Unix-domain socket inside the app container.

NoxKey — Keychain manager, noxkey.ai NoxViewer — issue triage, signed/notarized NoxFeed — sandboxed PR feed NoxPilot — PIM + MCP-over-socket
Edge & full-stack web

Production apps on Cloudflare's edge

Cloudflare Workers + D1 (SQLite) + R2 + Pages; Next.js static export and OpenNext-on-Workers; GitHub device-flow OAuth with server-proxied token refresh; Hono APIs; Better-Auth; Postmark. Including a multi-tenant AI dashboard with webhook ingestion into D1 and an org-scoped access model.

unticket — app.unticket.ai, source NoxSpot — app.noxspot.dev Boundless Learning — OpenNext on Workers 112Schade — Next.js 16 + FastAPI + Better-Auth

Technical capabilities, continued

AI-native systems

Agents as infrastructure, and real LLM pipelines

Headless claude -p agent orchestration across a multi-project workspace with scheduling and token-exhaustion recovery; a production narration pipeline (GitHub webhook → queue → LLM narrator → D1 store) that turns every PR into first-person team updates; MCP-first server design (tiered tools, directive instructions); local file/git/build watchers that stream agent activity.

Nox Agents — orchestration hub NoxLink — agent activity feed unticket — narration pipeline NoxKey — MCP server
Games, 3D & data

Real-time engines — and the data behind them

Bevy ECS (Rust) games and a 3D asset hub with a symlinked single-source-of-truth library (catalog.ron manifest) that propagates across projects; SQLite data modeling with idempotent ingest + per-row provenance; FastAPI + Vite/React/TS read-only viewers.

Character Gallery — Bevy 3D hub + editor AidenArena — Bevy combat game wow-arena-db — queryable game-data DB
Mobile

Native iOS & iPadOS

SwiftUI apps, including an iPad client that pairs to a web backend via pair-code authentication; xcodegen-managed projects for reproducible builds.

Robin — kids reading Baseline — health tracking noboxedu — iPad for Boundless Learning
